## Open source: ArikaJS

[**ArikaJS**](https://arikajs.github.io/) is a Node.js framework I created and maintain. It is TypeScript-first, with a CLI, an Active Record ORM, and built-in auth (JWT, sessions, OAuth).

```bash
npx @arikajs/cli new my-app
```

The ecosystem includes first-party packages:

- **Arika Socialite:** OAuth login with Google, GitHub, Facebook, and X
- **Arika Carbon:** immutable, timezone-aware date and time handling
- **Arika Sweet:** lightweight alerts and notifications with zero dependencies
- **Arika Deploy:** zero-config deploys with PM2, Nginx or Apache, and Let's Encrypt SSL

Read more on [prakashtank.com/arika-js](https://prakashtank.com/arika-js).
